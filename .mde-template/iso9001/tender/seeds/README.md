# The tenders

## TL;DR

This folder is the group's work on tenders: the calls collected, the register, the company profile, the tender documents,
the searches and the sheets. The ISO 9001 method created it once; from here on it belongs to the group and the method's
updates do not touch it.

- First of all fill in [the company profile](company-profile.md): without it, the agents stop and ask for it.
- Then collect the calls in [calls.md](calls.md) and put the tender documents in [tender-documents/](tender-documents/README.md).
- The round and who does what are in the [tender workflow](../.mde-template/iso9001/workflows/tender.md).

## What is here

| File or folder | Who writes it |
|---|---|
| `company-profile.md` | the leads, each their own chapter |
| `calls.md` | the group |
| `call-register.md` | the account manager's agent adds the line; the person writes the decision |
| `tender-documents/` | the group, one file per call that starts with the code |
| `searches/` | the account manager's agent |
| `sheets/` | the leads' agents (technical, contract, delivery) and the account manager's (review) |

The sheets are rewritten at every round: the versions of past rounds are in the git history, and the round log says which
commit was approved.
