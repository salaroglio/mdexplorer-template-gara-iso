# L'esempio

Questa cartella c'è solo nel ramo `esempio`: sono i file iniziali compilati per una gara di prova. Pentagroup (un'azienda
inventata) valuta il bando NC-2027-014 di Nordica Crediti (un committente inventato), il Progetto ATLANTE. La data di lavoro
è l'8 marzo 2027.

Chi crea un progetto «con l'esempio» riceve questi file in `gare/` al posto dei modelli vuoti. Tutti i dati sono inventati.
