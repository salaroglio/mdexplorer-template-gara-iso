# Le gare

## TL;DR

Questa cartella è il lavoro del gruppo sulle gare: i bandi raccolti, il registro, il profilo dell'azienda, i documenti di
gara, le ricerche e le schede. Il metodo «Gara con ISO 9001» l'ha creata una volta; da qui in poi è del gruppo e gli
aggiornamenti del metodo non la toccano.

- Prima di tutto compila [il profilo dell'azienda](profilo-azienda.md): senza, gli agenti si fermano e lo chiedono.
- Poi raccogli i bandi in [bandi.md](bandi.md) e metti i documenti di gara in [documenti-di-gara/](documenti-di-gara/README.md).
- Il giro e chi fa che cosa sono nel [workflow della gara](../.mde-template/gara-iso/workflows/gara.md).

## Che cosa c'è

| File o cartella | Chi lo scrive |
|---|---|
| `profilo-azienda.md` | i responsabili, ciascuno il suo capitolo |
| `bandi.md` | il gruppo |
| `registro-bandi.md` | l'agente dell'account manager aggiunge la riga; la decisione la scrive la persona |
| `documenti-di-gara/` | il gruppo, un file per bando che comincia con il codice |
| `ricerche/` | l'agente dell'account manager |
| `schede/` | gli agenti dei responsabili (tecnica, contrattuale, delivery) e dell'account manager (riesame) |

Le schede si riscrivono a ogni giro: le versioni dei giri passati stanno nella storia di git, e il registro dei giri dice
quale commit è stato approvato.
